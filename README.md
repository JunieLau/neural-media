## About the build

A static, bilingual (English + Simplified Chinese) tracker of everything public on
**Neural Media**, the concept by K Allado-McDowell. One unified timeline, newest
first, filterable by type.

## Add a daily update
1. Open `data/neural-media.json` and add an object anywhere in `items`. Order
   doesn't matter because the build sorts by `date`, newest first.
   ```json
   {
     "id": "2026-10-22-short-slug",
     "date": "2026-10-22",
     "types": ["post"],
     "added": "2026-10-22",
     "date_display": { "en": "22 Oct 2026", "zh": "2026 年 10 月 22 日" },
     "title":   { "en": "…", "zh": "…" },
     "summary": { "en": "…", "zh": "…" },
     "url": "https://…",
     "source":  { "en": "X (@kalladomcdowell)", "zh": "X（@kalladomcdowell）" },
     "links":   [ { "url": "https://…", "label": { "en": "…", "zh": "…" } } ],
     "thumbnail": "assets/some-video-thumb.jpg"
   }
   ```
   - `id`: unique slug.
   - `date`: `YYYY-MM-DD` in China time (UTC+8). This sets the order. If only the month is known, use day `01` and put the real precision in `date_display`.
   - `types`: one or more of `video`, `post`, `essay` (Essay/Paper), `interview`, `podcast`, `talk`, `exhibition`, `book`, `course`, `performance`, `context` (Wider context / 相关背景: K's activity not about neural media, or others' related work that doesn't engage K's framework). The labels live in the top-level `types` map.
   - `added`: the day you added the item. An item gets a **NEW** badge when `added` equals `meta.last_updated`.
   - `links` and `thumbnail` are optional. For a YouTube thumbnail, save `https://img.youtube.com/vi/<ID>/hqdefault.jpg` into `assets/`.
   - Every text field needs both `en` and `zh`. Only add verified facts that have a real source URL.
2. Rebuild and stamp today's date (UTC+8):
   ```bash
   python3 build.py --today
   ```
   Plain `python3 build.py` rebuilds without touching `meta.last_updated`. The build fails with a clear message if a field is missing, a type is unknown, a date is malformed or an id is duplicated.
3. Optional: refresh the screenshots with Playwright, or just open `index.html` (then use the nav to check `who-else.html`, `bci.html`, `new-models.html` and `felstead-leung.html`).

Other sections in the same file: `hero`, `concept.eras` (the four media types), `featured` (the Long Now video and its takeaways), `reading` (a list of item ids shown as key essays and sources) and `landscape`. In `landscape`, `groups[]` each have `key`, a bilingual `title`, an optional `note` and `entries[]`. Each entry has `name`, `line` (both `{en, zh}`), an https `url` and `marks`, chosen from `landscape.markers`: `term` (uses the term), `citesK`, `adjacent` or `different` (different meaning).

`bci` (section 06, BCI × Neural Media / 脑机接口与神经媒体) has bilingual `title`, `lead` and `note`, and `markers`
(`k` = K's framework, `theory`, `research`, `industry`, `law` = law & ethics). It has three parts:
- `primer.cards[]`: plain-language explainer cards, each with `term`, `text` (both `{en, zh}`) and an optional https `url`.
- `theory.entries[]`: ideas and thinkers, each with `name`, `source`, `line` (all `{en, zh}`), an https `url`, `marks`,
  and optional `links[]` (`url` plus a bilingual `label`). Only entries marked `k` are K's own statements.
- `news.entries[]`: dated BCI × AI news, each with `date` (`YYYY-MM-DD`), `date_display`, `title`, `line` (all `{en, zh}`),
  an https `url` and `marks`. Sorted newest first at render time.

`bci.feature` is the Phase Lock chapter shown at the top of `bci.html`: `kicker`, `title`, `subtitle`, `byline`,
`definition` (`word`, `quote`, `note`), `cta[]` (reading links; `primary: true` for the main button), `note`,
`author` (`title`, `text`, `links[]`), `argument.points[]` (`term`, `text`, optional short `quote` from the source),
`structure.parts[]` (`num`, `name`, `question`, `text`, `url`, `sections[]`), `versions.entries[]` (`date`, `label`, `text`)
and `chain.steps[]` (`date`, `who`, `what`, `url`) plus `chain.note`.

The build validates all of this (both languages, https links, known markers, valid dates), the same way it checks `landscape`.

**Pages and internal links.** The top-level `pages` list (keys `home`, `who-else`, `bci`, `new-models`, `felstead-leung`) sets the nav labels. A timeline item
or a theory entry can carry `"internal": {"href": "bci.html#phase-lock", "label": {en, zh}}` to link to another page of this
site; the build checks that the page and anchor exist. The renderer adds `?lang=` to internal links so the language choice survives
even where `localStorage` is unavailable.

**Videos / 视频.** Every YouTube link on every page is shown as a thumbnail cover with a play button
(`i.ytimg.com/vi/<id>/hqdefault.jpg`, lazy-loaded; the local `assets/` copy is used if it fails). Clicking it swaps in a
`youtube-nocookie.com` player that autoplays, on any http(s) host such as GitHub Pages. YouTube refuses embedded playback
for pages opened straight from disk (`file://`, its "Video player configuration error"), so there the click opens the
video on YouTube in a new tab instead. Each cover also has an "Open on YouTube ↗" link. Audio-only links (SoundCloud,
Spotify, Spreaker) stay as ordinary links.
所有页面上的 YouTube 视频都显示为带播放按钮的封面缩略图（懒加载）。在网页服务器上（例如 GitHub Pages）点击后会就地播放
（youtube-nocookie 播放器，自动开始）；直接从本地打开文件时，YouTube 不允许嵌入播放，点击会在新标签页打开 YouTube。
